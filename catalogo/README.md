# Catálogo: criterios

GitHub no es una copia del ERP. Registrar ejemplos verificables de referencias internas y dificultades de interpretación, pero no guardar cantidades actuales como datos estáticos.

Datos consultables bajo demanda:
- `default_code`: código interno.
- `name`: nombre comercial interno.
- `product_brand_id`: marca.
- `qty_available`: stock a mano (puede incluir reservas).
- `uom_id`: unidad de medida.

La presencia de un artículo activo no significa stock disponible. Para parámetros sensibles, cotejar el modelo con la ficha oficial del fabricante.
