# Pruebas de calidad del asistente

Cada caso debe indicar consulta, formato esperado, requisitos a verificar y resultados prohibidos.

- Consulta normal: buscar sin explicación extensa.
- Consulta «con explicación»: agregar 2–4 oraciones de función y aplicación.
- Diferenciales Schneider: distinguir SI/S, tipo A/AC, polos y sensibilidad.
- Schneider INS de 630 A: no confundir interruptor-seccionador INS con MCCB NS/NSX.
- Stock: mostrar solo `qty_available`, no suponer liberación de reservas.
- Códigos: no inventar referencias y no presentar la falta de una palabra en Odoo como ausencia confirmada de la característica.
