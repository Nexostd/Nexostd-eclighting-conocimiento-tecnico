# Reglas de cotización – familias y kits
Reglas internas de ECLIGHTING para armar pedidos. Las define el equipo; el asistente las aplica siempre que corresponda. Sin precios ni stock.

## R01 · Familia Zoloda para tablero (borneras)
**Cuándo aplica:** cuando piden "bornes Zoloda", "borneras Zoloda", "familia Zoloda para tablero" o un tablero que lleve borneras Zoloda.
**Qué ofrecer:** siempre el juego completo de estas 6 piezas, no solo el borne:

| Pieza | Qué es | Cómo figura en Odoo |
|---|---|---|
| BPN | Borne de paso a tornillo | BPN-2,5 / BPN-04 / BPN-06 / BPN-10 / BPN-16 / BPN-35 / BPN-50 (con variantes de color: -AZ azul, -VE verde, -RO rojo, etc.) |
| BSLKN | Borne de puesta a tierra | BSLKN-04 / -06 / -10 / -16 / -35 |
| D-BPN | Tapa final para borne BPN | D-BPN-2,5/10 (para BPN-2,5, 04, 06 y 10) · D-BPN-16/35 (para BPN-16 y 35) |
| JSSB | Puente fijo de 10 elementos para BPN | JSSB-10-05/BPN → BPN-2,5 · JSSB-10-06/BPN → BPN-04 · JSSB-10-08/BPN → BPN-06 · JSSB-10-10/BPN → BPN-10 · JSSB-10-12/BPN → BPN-16 · JSSB-10-16/BPN → BPN-35 · JSSB-03-20/BPN (3 elementos) → BPN-50 |
| EKN1 | Extremo / tope de bornera para riel NS-35 (DIN 35) | EKN1 |
| SE1 | Separador 64×52 mm | SE1 (2 mm) · SE1-D (1 mm, amarillo) · SE1-D-GR (1 mm, gris) |

**Cómo elegir dentro de la familia:**
1. La **sección del cable** define el borne BPN y, con él, la tapa D-BPN y el puente JSSB que corresponden (tabla de arriba).
2. Para tierra, BSLKN de la misma sección.
3. Tapas y puentes se eligen por el borne, no por separado: no mezclar tamaños.
4. Si no dicen la sección, mostrar la familia completa por sección y preguntar solo ese dato.
5. Los JSSB-xx/BKF son para bornes a **resorte** BKF, no para BPN: no ofrecerlos con BPN.

Fuente: descripciones de productos en Odoo (2026-10-28). Pendiente: cotejar con el catálogo vigente de Zoloda.
