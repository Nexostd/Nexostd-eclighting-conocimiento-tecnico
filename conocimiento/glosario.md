# Glosario rápido

| Sigla | Significado |
|---|---|
| MCCB | Interruptor automático de caja moldeada |
| MCB | Interruptor automático en miniatura (termomagnético modular) |
| RCCB | Interruptor diferencial sin protección integrada de sobrecorriente |
| RCBO | Interruptor diferencial con protección integrada de sobrecorriente |
| In | Corriente nominal |
| IΔn | Corriente diferencial residual asignada |
| kA | Kiloamperio; en protecciones suele expresar capacidad de corte, según el parámetro concreto |
| SI | Superinmunización a disparos intempestivos, según tecnología del fabricante |
| S | Selectividad diferencial con retardo, según modelo/norma |
| IP | Grado de protección frente a ingreso |
| IK | Grado de protección contra impactos |
| XLPE | Polietileno reticulado |
| LS0H/LSZH | Materiales con baja emisión de humo y libres de halógenos conforme a ensayos especificados |
| PAT | Puesta a tierra |
| AC-3 | Categoría de empleo para contactores, asociada a determinadas maniobras de motores |
| ID / IID / iID | Denominaciones comerciales de interruptor diferencial (según fabricante) |
| Disyuntor | Término de mostrador para interruptor diferencial |
| Térmica | Término de mostrador para interruptor termomagnético |
| Mignon | Caja de embutir 5x5 |
| Clase AC / A / B | Tipo de corriente de fuga que detecta el diferencial; propiedad independiente de SI y S |
