# Cómo aportar conocimiento

Para agregar una ficha o corrección:
1. Abrir una propuesta de cambio, idealmente en una rama o pull request.
2. Usar `plantillas/ficha-material.md` o `plantillas/correccion.md`.
3. Agregar referencia de fabricante o norma cuando sea una afirmación técnica.
4. Comprobar no haber incluido datos privados, credenciales, cotizaciones de clientes ni snapshots de stock.
5. Solicitar validación técnica para datos críticos.

## No publicar automáticamente
- Equivalencias entre dispositivos de protección no validadas.
- Valores de cortocircuito, configuración o dimensionado como garantías de seguridad.
- Códigos inventados o especulativos.
- Informes de stock como si fuesen valores permanentes.
