# Registrar un aprendizaje

1. Copiar la pregunta original (sin datos personales ni información sensible).
2. Identificar el error, omisión o ambigüedad de la respuesta del asistente.
3. Registrar el comportamiento correcto esperado.
4. Guardar la evidencia: catálogo oficial o ficha validada cuando haya datos técnicos.
5. Actualizar `agente/INSTRUCCIONES_TUQUI.md`, la ficha de conocimiento y/o un caso de prueba.
6. Solicitar validación técnica cuando corresponda antes de considerar una regla aprobada.

No transformar automáticamente una opinión o una descripción incompleta de Odoo en especificación técnica confirmada.
