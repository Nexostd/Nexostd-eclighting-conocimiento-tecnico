# Casos de cotizaciones — desidentificados

Para incorporar un caso, usar `plantillas/caso-de-cotizacion.md` o la plantilla de Issue **Caso de cotización técnica**. No colocar aquí los PDF, Excel o imágenes originales de clientes salvo anonimización y autorización explícitas. **Nunca guardar precios.**

Los casos nuevos comienzan como **pendientes**. No son fuente técnica aprobada por el simple hecho de haberse cotizado. Tras revisión, trasladar el conocimiento generalizable a `conocimiento/`, `catalogo/`, `agente/` y `pruebas/` cuando corresponda.

Evitar guardar repetidamente la misma consulta; preferir registrar el aprendizaje nuevo.
