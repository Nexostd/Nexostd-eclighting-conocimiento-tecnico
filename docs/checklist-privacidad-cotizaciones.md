# Lista de control antes de compartir una cotización

**Nunca enviar precios**: ni valores unitarios ni totales; tampoco costos, márgenes, descuentos, cotización de moneda, tarifas o condiciones de pago.

- [ ] Eliminé nombres y datos de contacto de personas y empresas clientes.
- [ ] Eliminé CUIT, domicilios, nombres de obras y ubicaciones que identifiquen al cliente.
- [ ] Eliminé correos electrónicos, teléfonos, direcciones, firmas y encabezados.
- [ ] Eliminé precios, subtotales, impuestos ligados a precios, totales, costos, descuentos y márgenes.
- [ ] Eliminé información privada de proveedores no autorizada para compartir.
- [ ] Eliminé URLs internas, IDs de oportunidades, archivos adjuntos confidenciales y notas comerciales.
- [ ] Revisé comentarios, metadatos, propiedades y hojas ocultas si se trata de Excel.
- [ ] Preservé solo descripciones, códigos técnicos, marcas, cantidades del pedido necesarias y justificación técnica.
- [ ] El documento se puede compartir conforme a las reglas internas de ECLIGHTING.

**Si no es posible desidentificar sin perder sentido, no compartir el archivo original.** En su lugar, transcribir manualmente una descripción técnica genérica.
