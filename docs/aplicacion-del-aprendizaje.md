# Aplicar el aprendizaje en ambas herramientas

## ChatGPT
En el proyecto TEMARIO TÉCNICO usar las reglas de `agente/INSTRUCCIONES_PARA_CHATGPT_ECLIGHTING.md`. Conectar y consultar el repositorio GitHub cuando haga falta recuperar el conocimiento validado. No todas las conversaciones nuevas incorporan automáticamente el contenido del repositorio.

## Tuqui
Usar `agente/INSTRUCCIONES_TUQUI.md` y la skill publicada en el workspace. Llevar cambios aprobados de GitHub a las instrucciones/skills/contexto del agente mediante un procedimiento explícito. No hay sincronización automática solo por tener GitHub conectado a ChatGPT.

## ERP
Odoo sigue siendo la fuente de códigos y stock en vivo. No copiar bases sensibles ni snapshot de stock al repositorio.

## Una corrección bien cerrada incluye
Una lección, una fuente confiable cuando es técnica, al menos un caso de prueba, aprobación y confirmación de que el cambio llegó al agente que usará el equipo.
